<a id="setup-instructions"></a>
## 🔧 Setup Instructions


Follow these steps:

* Clone the repository
* Install dependencies
* Start the server

```bash
npm install
```

Run the project:

```bash
node app.js
```

Open in browser:

```
http://localhost:3000
```

<a id="tasks-overview"></a>
## 📚 Tasks Overview

### 🟢 Level 1: Foundations

**Task 1: Hello World**

* Render static text using EJS

**Task 2: Multiple Variables**

* Pass strings, numbers, booleans

**Task 3: EJS Comments**

* Use `<%# %>` for hidden notes

---

### 🟡 Level 2: Control Flow

**Task 4: Conditional Logic**

* Show UI based on role

**Task 5: Loop Basics**

* Render arrays using `for` loop

**Task 6: forEach Refactor**

* Replace loops with `.forEach()`

---

### 🟠 Level 3: Data Handling

**Task 7: Arrays of Objects**

* Render table from structured data

**Task 8: Nested Data**

* Handle categories and items

**Task 9: Dynamic Dashboard**

* Role-based UI rendering

---

### 🔴 Level 4: Advanced Logic

**Task 10: Filtering & Styling**

* Use `.filter()` and `.forEach()`
* Apply dynamic styles
