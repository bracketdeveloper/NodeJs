---

<a id="setup-instructions"></a>

## 🔧 Setup Instructions

Clone the repository:

```bash
git clone https://github.com/bracketdeveloper/NodeJs.git
```

Move into folder:

```bash
cd "NodeJs/Form Validation"
```

Install dependencies:

```bash
npm install
```

Start server:

```bash
node index.js
```

Open in browser:

http://localhost:3000
